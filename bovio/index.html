Bovio runs on Discord slash commands. No setup, no permissions to wire up — just install and play.

1

Add Bovio to your server

One click in Discord — pick a server you administer, confirm the bot scope. Bovio joins read-only and only listens to slash commands.

2

Type /start

Bovio generates a secret 4-digit code — all unique digits — and starts a match in that channel. Anyone in the channel can play.

3

Guess with /guess

Each guess returns bulls 🐂 (right digit, right place) and cows 🐄 (right digit, wrong place). Close in on the code.
